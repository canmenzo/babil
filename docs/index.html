Install

Running in about two minutes

  1. Download the ZIPGrab the Babil ZIP from the latest release and unzip it.
  2. Open the extensions pageType chrome://extensions in the address bar and turn on Developer mode.
  3. Load unpackedClick Load unpacked and choose the folder that contains manifest.json. Pin Babil from the puzzle piece menu.
  4. Start captionsPlay a video, choose your language, and press the big button or Alt+Shift+T. The first start downloads a speech model of about 600 MB. After that it is saved.
Requirements. Chrome 138 or newer, or Firefox 142 or newer, on a desktop computer. A graphics card makes it faster.
Firefox. The Firefox build is not in the release ZIP yet. Build it from source with npm install and npm run build:firefox, then load dist-firefox/manifest.json from about:debugging#/runtime/this-firefox using Load Temporary Add-on. The first Firefox translation downloads an extra model of up to about 1.1 GB.

Privacy

Your audio stays on your computer

Speech recognition and translation both run locally, so nothing you watch is uploaded for processing. There is no account to create and no server of ours in the loop. The code is MIT licensed and public on GitHub, so you can check it yourself.

FAQ

Questions people ask

Is Babil really free?

Yes. There is no paid tier, no trial and no API key to buy.

Which sites does it work on?

YouTube, Twitch, Kick and other sites with a standard video player. On Firefox, protected media and players that do not expose an audio track cannot be captured.

Why is the first start slow?

Babil downloads a Whisper speech model once, about 600 MB on automatic. Later starts reuse the saved copy.

How do I get better accuracy?

Select the video's spoken language instead of leaving it on automatic detection.

How do I update?

Babil's panel tells you when an update is ready. Download the new ZIP, unzip it over your existing Babil folder, then click reload in the update notice. Settings and models are kept.

Is it in the Chrome Web Store?

Not yet. For now, install it from the GitHub release as described above.
