用你的母语看任何视频

Babil 为 YouTube、Twitch、Kick 等网站上的视频加上实时字幕，并翻译成 26 种语言。一切都在你的电脑上运行。

功能

跟得上视频节奏的字幕

26 种语言

选好你想要的语言，Babil 会在视频播放的同时翻译其中的语音。

原文译文同屏显示

两行字幕同时显示，全屏时也一样。学外语时尤其有用。

字幕随你设置

把字幕拖到任意位置，字体、字号和颜色都能调到你满意为止。

免费，本地运行

无需订阅，无需账号，无需 API 密钥。语音识别由 Whisper 完成，直接在你的浏览器里运行。

听译文

开启朗读后，Babil 会读出每一句译文，朗读时自动调低视频音量。选一个声音（若兰、暖暖、海川、浩然、静怡或飞扬），先点“试听”听听效果。Babil 优先使用你电脑上的语音，只要有本地语音可用，字幕就不会交给在线语音。看字幕看累了的时候特别方便。

每个视频里，都有一种你还不会说的语言。Babil 在你观看时消除这道隔阂，而且不会把哪怕一秒钟的音频发送到任何地方。

安装

大约两分钟就能用上

  1. 从 Chrome 应用商店添加打开Chrome 应用商店中的 Babil 页面，点击“添加至 Chrome”。
  2. 固定 Babil在工具栏中打开拼图形状的扩展程序菜单，固定 Babil，让它的图标随时可用。
  3. 开始字幕播放视频，选择你的语言，然后点击大按钮或按 Alt+Shift+T。首次启动会下载一个约 600 MB 的语音识别模型，之后会一直保存在本地。
系统要求：电脑上的 Chrome 138 或更高版本，或 Firefox 142 或更高版本（不支持手机）。有显卡会更快。
Firefox：请从Firefox 附加组件网站安装 Babil。在 Firefox 中第一次翻译时，还会额外下载一个最大约 1.1 GB 的模型。

隐私

你的音频只留在你的电脑上

语音识别和翻译都在本地完成，你看的任何内容都不会被上传处理。无需注册账号，中间也没有我们的服务器。代码采用 MIT 许可证，在 GitHub 上公开，你可以亲自检查。

常见问题

大家常问的问题

Babil 真的免费吗？

是的。没有付费版，没有试用期，也不需要购买 API 密钥。

支持哪些网站？

YouTube、Twitch、Kick 以及其他使用标准视频播放器的网站。在 Firefox 中，受保护的媒体和不提供音轨的播放器无法捕获。

为什么第一次启动比较慢？

Babil 需要下载一次 Whisper 语音识别模型，选“自动”时约 600 MB。之后启动会直接使用已保存的副本。

怎样提高识别准确度？

把“原声语言”设为视频里实际说的语言，不要停留在“自动检测”。

如何更新？

从 Chrome 应用商店或 Firefox 附加组件网站安装的版本，在那里发布新版本后会由浏览器自动更新。通过 ZIP 或临时方式安装的，需要替换文件，然后在浏览器的扩展程序页面重新加载扩展。设置和模型都会保留。
